Criando dados

INSERT

Adicionando uma linha de cada vez.

-- Forma completa (explícita)
INSERT INTO contas (login, email, senha_hash, data_criacao, ativo)
VALUES ('arthas', 'arthas@rpg.com', 'hash_aqui', GETDATE(), 1);

-- Forma curta (sem colunas, só funciona se passar valor pra todas, na ordem)
INSERT INTO contas
VALUES ('jaina', 'jaina@rpg.com', 'hash_aqui', GETDATE(), 1);
Dica Use a forma explícita. Se alguém adicionar uma coluna nova, a forma curta quebra. A explícita continua funcionando.
Criando dados

Vários de uma vez

Mais eficiente do que rodar um INSERT por linha.

INSERT INTO classes (nome, descricao)
VALUES
  ('Guerreiro', 'Força física, vida alta'),
  ('Mago', 'Mana alta, magias poderosas'),
  ('Arqueiro', 'Ágil, ataque à distância'),
  ('Curandeiro', 'Suporte, magias de cura');
Observe Lembrou que IDENTITY é automático? Não precisa passar o id. O SQL Server gera (1, 2, 3, 4).
Lendo dados

SELECT

Pergunta ao banco: "me mostra o que tem aí".

-- Todas as colunas, todas as linhas
SELECT * FROM contas;

-- Colunas específicas
SELECT login, email FROM contas;

-- Com alias (renomeando a coluna no resultado)
SELECT login AS usuario, email AS contato FROM contas;
Cuidado SELECT * é ótimo pra explorar, mas em produção evite. Liste as colunas que você realmente precisa.
Filtrando

WHERE

"Me mostra só os que..."

-- Igualdade
SELECT * FROM personagens WHERE nivel = 10;

-- Diferente
SELECT * FROM personagens WHERE classe_id != 2;

-- Maior, menor, etc
SELECT * FROM personagens WHERE nivel >= 50;

-- Combinando condições
SELECT * FROM personagens
WHERE nivel >= 50 AND classe_id = 1;

Filtrando

Operadores em ação

-- Personagens entre nível 10 e 20
SELECT nome, nivel FROM personagens
WHERE nivel BETWEEN 10 AND 20;

-- Items raros ou épicos
SELECT * FROM items
WHERE raridade IN ('Raro', 'Épico');

-- Personagens com "dragon" no nome
SELECT * FROM personagens
WHERE nome LIKE '%dragon%';

-- Contas que ainda não logaram
SELECT * FROM contas
WHERE data_ultimo_login IS NULL;
Modificando dados

UPDATE

Mudar valores de registros que já existem.

-- Sintaxe completa
UPDATE personagens
SET nivel = nivel + 1,
    experiencia = 0
WHERE id = 42;

-- Atualizar várias linhas com um critério
UPDATE personagens
SET vida_max = vida_max + 10
WHERE classe_id = 1;  -- todos os guerreiros
Atenção Sempre com WHERE. UPDATE sem WHERE altera todas as linhas da tabela.
Removendo dados

DELETE

Remover registros. Operação destrutiva, sem volta sem backup.

-- Remover um personagem específico
DELETE FROM personagens
WHERE id = 42;

-- Remover todos os personagens inativos
DELETE FROM personagens
WHERE ativo = 0;
Cuidado DELETE sem WHERE apaga todas as linhas da tabela. Não tem undo. Antes de rodar em produção: SELECT primeiro com o mesmo WHERE pra ver o que vai sumir.
Boas práticas

A regra dos 3 segundos

Antes de apertar F5 num UPDATE ou DELETE, pare e olhe.

1. Você escreveu o WHERE?

UPDATE/DELETE sem WHERE = bomba atômica.

2. Você rodaria o SELECT primeiro?

Troque UPDATE/DELETE por SELECT e veja exatamente quais linhas vão ser afetadas.

3. Você está no banco certo?

Olhe pro cantinho do SSMS. "rpg_game" ou "rpg_game_prod"?

História real Todo DBA tem uma cicatriz de UPDATE sem WHERE em produção. Não seja a próxima estatística.

Aplicando no RPG

Simulando ações do jogador

-- Personagem ganha level up
UPDATE personagens
SET nivel = nivel + 1,
    vida_max = vida_max + 5,
    mana_max = mana_max + 3,
    experiencia = 0
WHERE id = 1;

-- Banir conta por mau comportamento
UPDATE contas
SET ativo = 0
WHERE login = 'troll123';

-- Apagar personagem deletado pelo jogador
DELETE FROM personagens
WHERE id = 7;
Boas práticas

Antes de seguir em frente

  1. INSERT explícitoSempre liste as colunas. Protege contra mudanças no schema.
  2. SELECT antes de UPDATE/DELETEVeja o que vai ser afetado antes de modificar.
  3. WHERE sempreUPDATE e DELETE sem WHERE alteram tudo.
  4. Não use = NULLUse IS NULL / IS NOT NULL. NULL não é igual a nada, nem a si mesmo.
  5. Cuidado com banco de produçãoVeja onde você está conectado antes de rodar.

Desafio em aula

Popule o RPG

~25 minutos. Use o banco criado na Aula 1.5.

  • Insira pelo menos 5 contas
  • Insira pelo menos 4 classes (Guerreiro, Mago, Arqueiro, Curandeiro)
  • Insira pelo menos 3 personagens por conta
  • Insira pelo menos 10 items variados
  • Faça um UPDATE dando level up em todos os personagens nível 1
  • Faça um DELETE removendo personagens inativos (se houver)
Pegadinha Antes de rodar o DELETE, faça um SELECT pra ver o que vai sumir. Cole o resultado no chat pra mostrar.
